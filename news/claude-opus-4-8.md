# Claude Opus 4.8 Announcement

**Date:** May 28, 2026

## Overview

Anthropic unveiled Claude Opus 4.8, an upgraded version of Opus 4.7 featuring improvements across benchmarks while maintaining the same pricing structure. The release includes several companion features and capabilities enhancements.

## Key Improvements

**Performance Gains:**
- Enhanced coding, reasoning, and agentic skills
- Improved reliability in agent tasks
- Better judgment and decision-making capabilities

**Pricing:**
- Regular usage: $5 per million input tokens, $25 per million output tokens (unchanged)
- Fast mode: $10 per million input tokens, $50 per million output tokens (3x cheaper than previous models)

## Major Features Launching Today

1. **Dynamic Workflows** - Allows Claude to manage hundreds of parallel subagents for large-scale tasks like codebase migrations spanning hundreds of thousands of lines

2. **Effort Control** - New toggle in claude.ai letting users select how much computational effort Claude applies to responses, balancing quality against rate limit usage

3. **Messages API Update** - System entries can now be inserted within message arrays, enabling mid-task instruction updates without breaking prompt cache

## Notable Qualities

According to testers, Opus 4.8 demonstrates enhanced "honesty" -- it's approximately four times less likely than its predecessor to overlook code flaws. The alignment assessment indicates the model achieves "new highs" on prosocial measures while reducing misaligned behaviors.

## Availability

Available immediately across all platforms via the identifier `claude-opus-4-8`.
