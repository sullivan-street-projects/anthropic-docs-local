# Expanding the Cyber Verification Program

Anthropic, **October 6, 2026**. The expanded Cyber Verification Program (CVP) gives qualifying security professionals access to advanced cyber capabilities and reduced blocking classifiers, merging Project Glasswing and the original CVP into three tiers. Each tier includes Opus 5.5, Sonnet 5.5, Mythos 5.1, and future models.

- **Defense Access:** defensive work (SecOps, IR, malware RE, vulnerability validation); response within a few days.
- **Red Team Access:** adds authorized pen-testing/red-teaming (organizations only); real-time blocks remain for ransomware deployment and high-risk safety-system pen-testing.
- **Specialized Access:** fewest blocks; verified organizations authorized to test safety-critical systems (power grids, flight ops), reviewed with the US government. Existing Glasswing members move here without reapproval.

**Data retention:** enrolled orgs must retain data for misuse monitoring; Enterprise Frontier Safeguards (own-cloud storage) expected later this fall; ZDR models can use CVP with zero data retention until then.

**Efficacy (CyScenarioBench):** Opus 5.5 blocked 46/50 in Defense Access; no blocks in Red Team Access (34/50 tasks, matching 67.6% no-safeguard rate).

**Glasswing impact:** partners reported ≥129,000 verified vulnerabilities (Apr–Jul 2026); OSS scanning found 5,500 more (Apr–Oct 2026); 33,000+ rated critical/high. Available on the Claude Platform, Google Cloud Vertex AI, and Microsoft Foundry (Bedrock limited to EFS-eligible customers).
