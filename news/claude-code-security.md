# Claude Code Security: Frontier Cybersecurity Now Available

**Publication Date:** February 20, 2026

## Overview

Anthropic introduced Claude Code Security, a new capability integrated into Claude Code on the web available through limited research preview. The tool examines codebases for security vulnerabilities and proposes targeted patches for human review, enabling teams to identify issues that conventional methods typically overlook.

## Key Features

The system operates differently from traditional static analysis. Rather than matching code against known vulnerability patterns, it "reads and reasons about your code the way a human security researcher would," understanding component interactions and data flows to catch complex vulnerabilities in business logic and access controls.

Every finding undergoes multi-stage verification before reaching analysts, with Claude attempting to validate or refute its own discoveries and filter false positives. The platform assigns severity ratings and confidence scores for each finding, ensuring developers maintain final approval authority.

## Access and Availability

The limited research preview opens to Enterprise and Team customers, with expedited access available for open-source maintainers. Interested parties can apply at the official contact page.

## Supporting Research

This release builds on extensive cybersecurity research. Claude's Frontier Red Team has systematically tested defensive capabilities through competitive challenges, critical infrastructure partnerships, and real-world vulnerability discovery. Using Claude Opus 4.6, the team identified "over 500 vulnerabilities" in production open-source code that had evaded detection for decades.
