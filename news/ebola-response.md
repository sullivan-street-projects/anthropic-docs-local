# The Situation Report

Anthropic, **September 22, 2026**. Documents how Claude is being used in the response to the Bundibugyo ebolavirus (BDBV) outbreak in eastern Democratic Republic of the Congo, an outbreak with no approved vaccine and a fatality rate near 48%.

## Key Uses

- **Situation reports:** WHO AFRO built a Claude skill that pulls case and lab numbers from health zones' slide decks, checks them against the previous day's report, flags trend changes, and summarizes the reports. Work that took a full day can now be done in under an hour.
- **Disease modeling:** Data teams run several disease models simultaneously and build forecasts to guide decisions such as where to build treatment centers.
- **Vaccine development:** CEPI used Claude to organize multi-factor data across vaccine proposals and built a dashboard to track development work. Experts still make the scientific judgments.
- **Genomics:** The INRB lab uses Claude Science to assemble virus genomes and build phylogenetic trees, helping trace infections and identify variants.
- **Other uses:** WHO AFRO is also using Claude to clean outbreak line lists for a chikungunya outbreak and plans to link historical disease databases for future responses.

## Key Takeaways

The outbreak shows some signs of slowing in Ituri province. Quoted sources include Dr. Jean-Jacques Muyembe and Polina Brangel of CEPI.
