# Introducing a way to reflect on how you use Claude

**Date:** Jul 9, 2026

## Overview

Anthropic has launched a beta feature enabling users to examine and optimize their Claude usage patterns. The tool addresses a key user need: understanding how to integrate AI effectively into daily workflows.

## Key Features

### Usage Tracking & Visualization

The reflection dashboard displays Claude activity across customizable timeframes (1, 3, 6, or 12 months), breaking down usage by topic and task type. Users can examine when they use Claude most and what activities consume their time.

### Reflective Prompts

The system surfaces periodic questions like, "What's one thing you want to keep doing yourself, even if Claude could do it faster?" enabling deeper consideration of AI's role in your life.

### Usage Management Tools

- Quiet hours scheduling
- Break reminders after specific usage durations
- Both features are dismissible

### 4D AI Fluency Framework Integration

The reflection report maps user behavior across four dimensions:

- **Delegation** 
- **Description**
- **Discernment**
- **Diligence**

Users receive personalized examples and actionable suggestions for improving their AI collaboration skills.

## Privacy Safeguards

The feature explicitly excludes incognito chats and underlying files from connected tools. Insights remain isolated within the reflection dashboard and aren't repurposed elsewhere. The development involved experts from MIT Media Lab, Boston Children's Hospital, and the Family Online Safety Institute.

## Availability

Currently in beta for Free, Pro, and Max users with Memory enabled, accessible through Settings in Claude on web or desktop.
