# Claude Tag: Introducing AI Collaboration in Slack

**Published:** June 23, 2026

## Overview

Anthropic has launched Claude Tag, a Slack-integrated feature enabling teams to collaborate with Claude as a team member. Users tag @Claude with requests, and the AI assists with tasks while remaining integrated within team workflows.

## Key Features

**Multiplayer Functionality**
"Within a given Slack channel, there's one Claude that interacts with everyone," allowing team members to observe ongoing work and continue conversations seamlessly.

**Contextual Learning**
Claude builds understanding over time by following channel conversations and can access connected data sources and tools when granted permission, reducing repetitive explanations.

**Proactive Assistance**
When enabled, Claude flags relevant information across accessible channels and tools, following up on unresolved tasks autonomously.

**Asynchronous Operations**
Users can delegate tasks and focus elsewhere while Claude works independently, even scheduling activities across multiple days.

## Access and Administration

Claude Tag is available in beta for Claude Enterprise and Team customers. Administrators control tool access, information availability, and spending limits while maintaining strict data isolation between different Claude instances.

## Implementation Requirements

Setup involves four steps: pairing with Slack workspace, granting tool access, establishing spending limits, and testing in a private channel.

**Model:** Requires Claude Opus 4.8
