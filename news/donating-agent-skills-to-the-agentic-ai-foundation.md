# Donating Agent Skills to the Agentic AI Foundation

Anthropic, **October 22, 2026**. Anthropic is donating **Agent Skills** — the open standard that gives AI agents specialized knowledge and workflows — to the **Agentic AI Foundation (AAIF)**, which operates under the Linux Foundation.

## What was donated

The donation includes the standard itself, the **Agent Skills name and logo**, the **GitHub organization**, and the **agentskills.io** domain. AAIF — which Anthropic co-founded with **Block** and **OpenAI**, and which already received the **Model Context Protocol (MCP)** — will serve as a neutral home so the community can help decide the standard's future.

## Why

A skill is a folder containing a `SKILL.md` file plus any needed scripts or reference material. Anthropic created skills while building Claude Code, because the tool handled general knowledge work well but lacked the procedural knowledge needed for real business tasks.

Adoption has been broad: since Anthropic published the standard in **December 2025**, more than **70 agent platforms** — including ChatGPT, Cursor, GitHub Copilot, and VS Code — have integrated it. Since the **October 2025 launch**, **1 million skills** have been published and nearly **280 million** have been installed.

## Governance

Companies can use or contribute to the standard without joining AAIF. Engineers from Anthropic, Google, OpenAI, and other companies will maintain it as individuals, with **David Soria Parra** and **Mahesh Murag** as Lead Maintainers. The proposed roadmap includes versioned releases, a formal proposal process, and security guidance for skill authors and installers; feedback on specification changes can be shared through the project's Discord.

Anthropic states: "We're committed to keeping Agent Skills open, community-driven, and vendor-neutral."
