# How AI Assistance Impacts the Formation of Coding Skills

## Overview

Anthropic researchers conducted a randomized controlled trial examining whether AI coding assistance helps or hinders skill development. The study involved 52 software developers learning a new Python library (Trio).

## Key Findings

**Mastery Impact**: Participants using AI scored significantly lower on comprehension assessments. "On a quiz that covered concepts they'd used just a few minutes before, participants in the AI group scored 17% lower than those who coded by hand" — equivalent to nearly two letter grades.

**Productivity Gains**: AI users finished tasks approximately two minutes faster, though this difference wasn't statistically significant.

**Quality Dependency**: How developers used AI mattered considerably. Those who combined code generation with follow-up questions and conceptual inquiries retained more knowledge than those who simply delegated tasks to the assistant.

## Study Design

Researchers recruited mostly junior developers with Python experience but unfamiliarity with the Trio library. The study consisted of a warm-up phase, coding tasks requiring asynchronous programming knowledge, and comprehension quizzes.

Assessment focused on debugging, code reading, and conceptual understanding — skills crucial for overseeing AI-generated code.

## AI Interaction Patterns

**Low-Scoring Patterns** (average <40%):
- AI delegation: Complete reliance on AI for code generation
- Progressive reliance: Initial independence followed by total delegation
- Iterative debugging: Over-reliance on AI for problem-solving

**High-Scoring Patterns** (average >=65%):
- Generation-then-comprehension: Followed code creation with clarifying questions
- Hybrid code-explanation: Requested explanations alongside generated code
- Conceptual inquiry: Asked only concept-focused questions; resolved errors independently

## Implications

The research suggests workplace AI adoption involves trade-offs. Organizations should design systems encouraging continuous learning rather than pure efficiency gains, particularly for junior developers who need skill development for effective AI oversight.

The researchers emphasize that "productivity gains matter, but so does the long-term development of the expertise those gains depend on."
