# Claude Apps Release Notes

Updates to Claude consumer and business applications.

> For developer platform release notes, see [Platform Release Notes](platform.md).

---

## August 2026

### August 6, 2026

- Skill and plugin security scanning (beta): Enterprise plans can enable automated checks for malicious content in third-party skills and plugins during upload or editing

---

## July 2026

### July 24, 2026

- Claude Opus 5 launched, described as a thoughtful and proactive model that comes close to the frontier intelligence of Claude Fable 5 at half the price

### July 14, 2026

- HIPAA self-serve configuration: organizations can independently manage HIPAA readiness for Claude Enterprise and API products through a streamlined administrative flow

### July 10, 2026

- Updated memory system: memory shifted from daily summaries to a set of individual, categorized entries that Claude reads and updates during conversations

### July 9, 2026

- New monthly recap feature at Settings > Reflect showing topics, activity patterns, and work observations (beta on Free, Pro, Max)
- Settings > Time and focus allows optional break reminders and quiet hours

### July 7, 2026

- Claude Cowork now available on web and mobile alongside desktop
- Cowork runs sessions remotely (in beta), so sessions and files are saved to accounts across devices
- Microsoft 365 connector gains write tools for email, calendar, and file management
- Teams connector remains read-only

### July 1, 2026

- Access restored to Claude Fable 5 and Claude Mythos 5
- Enterprise plans can now control model access and effort level settings via admin controls

## March 2026

### March 25, 2026

- Interactive apps in Claude for iOS and Android: pull up live charts, sketch diagrams, and build shareable assets directly within conversations.

### March 23, 2026

- Computer use research preview in Cowork and Claude Code + Dispatch improvements. Pro and Max users can grant Claude access to computer functions; Claude can open files, run dev tools, point, click, and navigate.

### March 17, 2026

- Control Cowork from your phone with a persistent thread (research preview for Pro/Max). Users access persistent agent threads via Claude Desktop or mobile apps to manage Cowork tasks.

### March 12, 2026

- Claude now creates custom charts, diagrams and other visualizations in-line in its responses.

### March 11, 2026

- Excel and PowerPoint add-ins improved to share full conversation context. Skills support and LLM gateway connectivity added for Bedrock, Vertex AI, and Microsoft Foundry users.

### March 2, 2026

- Memory capabilities now available to all Claude users, including free plans. Users can build on previous context through chat history, with chat search functionality and the ability to import/export memory data.
