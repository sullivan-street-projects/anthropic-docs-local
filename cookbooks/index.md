# Claude Cookbooks

Code and guides designed to help developers build with Claude, offering copy-able code snippets for easy integration into projects.

## Prerequisites

- Claude API key (sign up at [anthropic.com](https://www.anthropic.com))
- Examples primarily in Python (concepts adapt to any language)
- Recommended: Complete the [Claude API Fundamentals course](https://github.com/anthropics/courses/tree/master/anthropic_api_fundamentals)
