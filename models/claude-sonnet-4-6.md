# Introducing Claude Sonnet 4.6

**Date:** February 17, 2026

## Overview

Claude Sonnet 4.6 represents the most advanced iteration of the Sonnet model line. The update encompasses improvements across coding, computer use, extended context reasoning, agent planning, knowledge work, and design capabilities. A notable feature is the 1M token context window currently in beta.

## Availability and Pricing

Users on Free and Pro plans now access Sonnet 4.6 as the default model in Claude.ai and Claude Cowork. Pricing remains consistent with Sonnet 4.5, beginning at $3/$15 per million tokens.

## Key Improvements

### Coding Capabilities

Developers with early access prefer Sonnet 4.6 to its predecessor by a substantial margin. Many even favor it over Claude Opus 4.5 from November 2025. The model demonstrates enhanced consistency, instruction adherence, and reduced overengineering tendencies.

### Performance Benchmarks

Sonnet 4.6 approaches Opus-level intelligence at a more practical price point. It achieves "frontier-level performance on real-world, economically valuable office tasks" that previously required premium models.

### Safety Evaluation

Extensive safety assessments indicate Sonnet 4.6 is as safe as or safer than recent Claude models. Safety researchers noted its "broadly warm, honest, prosocial" character with "very strong safety behaviors."

## Computer Use Capabilities

Since October 2024, Anthropic has developed general-purpose computer-using models. OSWorld benchmark data demonstrates steady progress across sixteen months of Sonnet model development. Early users report "human-level capability" in tasks like spreadsheet navigation and multi-step web form completion.

### Security Considerations

The model shows major improvements in resistance to prompt injection attacks compared to Sonnet 4.5 and performs similarly to Opus 4.6 in this regard.

## Extended Context Window

The 1M token capacity accommodates entire codebases, lengthy contracts, or dozens of research papers simultaneously. Critically, "Sonnet 4.6 reasons effectively across all that context," supporting improved long-horizon planning.

### Vending-Bench Arena Results

In competitive simulations, Sonnet 4.6 demonstrated strategic sophistication by investing heavily in early capacity before pivoting sharply toward profitability in final phases, outperforming competitors.

## User Feedback and Applications

### Development

In Claude Code testing, users preferred Sonnet 4.6 over Sonnet 4.5 approximately 70% of the time. Approximately 59% preferred it to Opus 4.5, citing superior instruction following and fewer false success claims.

### Design and Frontend

Customers independently noted "notably more polished" visual outputs with superior layouts, animations, and design sensibility. Production-quality results required fewer iteration cycles.

### Document Analysis

The model matches Opus 4.6 performance on OfficeQA, which "measures how well a model can read enterprise documents, pull facts, and reason from those facts."

## Enterprise Customer Testimonials

**Databricks:** Sonnet 4.6 achieves parity with Opus 4.6 on document comprehension tasks -- "a meaningful upgrade for document comprehension workloads."

**Replit:** "The performance-to-cost ratio of Claude Sonnet 4.6 is extraordinary" and "keeps improving the higher you push the effort settings."

**GitHub:** "Claude Sonnet 4.6 is already excelling at complex code fixes, especially when searching across large codebases is essential."

**Pace:** Achieved "94% on our insurance benchmark, making it the highest-performing model we've tested for computer use."

**Zapier:** "Sonnet 4.6 is a significant leap forward on reasoning through difficult tasks" -- particularly strong on multi-step workflows and conditional logic.

## Platform Updates

- Adaptive and extended thinking modes are now available
- Context compaction (beta) automatically summarizes older context
- Web search and fetch tools now automatically filter and process results
- Code execution, memory tools, and tool calling are now generally available
- Claude in Excel now supports MCP connectors for external data sources

## Recommendations

Opus 4.6 remains optimal for tasks demanding "the deepest reasoning," including codebase refactoring and multi-agent coordination where precision is paramount.

## Access

Claude Sonnet 4.6 is available across all Claude plans, Claude Cowork, Claude Code, the API, and major cloud platforms. Developers can begin using it immediately via the Claude API with the model identifier `claude-sonnet-4-6`.
