# Introducing Claude Opus 4.7

**Release Date:** April 16, 2026

## Key Features

### Advanced Coding Capabilities

Opus 4.7 represents a significant advancement in software engineering tasks. The model "handles complex, long-running tasks with rigor and consistency" and demonstrates enhanced ability to verify its own outputs before reporting results.

### Enhanced Vision

The model now processes images up to 2,576 pixels on the long edge (approximately 3.75 megapixels) -- more than three times the capacity of earlier Claude versions. This improvement enables detailed work such as computer-use agents reading dense screenshots and data extraction from complex diagrams.

### Instruction Following

A notable improvement involves literal adherence to instructions. Users should expect that "prompts written for earlier models can sometimes now produce unexpected results" since the model takes instructions more literally than previous versions.

## Pricing

Pricing remains unchanged from Opus 4.6:

- **Input tokens:** $5 per million
- **Output tokens:** $25 per million

API identifier: `claude-opus-4-7`

## Availability

Opus 4.7 is available across:

- Claude platform (claude.ai)
- Claude API
- Amazon Bedrock
- Google Cloud Vertex AI
- Microsoft Foundry

## Notable Updates

**Effort Levels:** A new `xhigh` ("extra high") effort level provides finer control between reasoning depth and latency.

**Tokenization:** An updated tokenizer improves text processing but increases token consumption approximately 1.0-1.35x depending on content type.

**Cybersecurity Safeguards:** The model includes automatic detection and blocking for high-risk cybersecurity requests, with a Cyber Verification Program available for legitimate security professionals.

## Performance Highlights

Early testing from 28+ partner organizations showed consistent improvements in:

- Coding task resolution (up to 3x more production tasks resolved)
- Financial analysis and structured reasoning
- Legal document review and interpretation
- Long-context task management and autonomy
- Multimodal understanding and visual analysis
