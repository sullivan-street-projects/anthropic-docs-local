# Claude Opus 4.8

**Release Date:** May 28, 2026

## Key Features

### Model Improvements

- Enhanced performance across coding, agentic reasoning, and knowledge work tasks
- Approximately four times less likely than Opus 4.7 to overlook code flaws
- Improved "honesty" - more likely to flag uncertainties and avoid unsupported claims
- Better judgment in agentic tasks and stronger tool-calling efficiency

### New Capabilities

- **Dynamic Workflows** (Claude Code): Enables parallel subagent execution for large-scale tasks like codebase migrations across hundreds of thousands of lines
- **Effort Control**: Users can adjust computational effort (lower, high, extra, max) to balance speed and quality
- **Messages API Enhancement**: System entries can now be inserted mid-conversation without breaking prompt cache
